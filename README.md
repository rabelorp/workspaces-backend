## Descrição

O sistema Rabelodigital é uma solução completa para a gestão de estações de trabalho e reservas em ambientes de coworking, desenvolvido para atender tanto administradores quanto usuários finais. A aplicação é dividida em duas partes principais:

- Versão Web (Administradores): Utilizada pelos administradores do sistema para gerenciar estações de trabalho, incluir, editar e excluir reservas, além de enviar notificações e gerar relatórios.

- Versão Mobile (Usuários Finais): Utilizada pelos usuarios para fazer reservas, check-ins, e gerenciar suas interações com as estações de trabalho e salas disponíveis, com funcionalidades adicionais como geolocalização e integração com o sistema de segurança.
