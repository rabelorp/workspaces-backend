## Geração de recurso

Gere o recurso com os seguintes comandos:
 

### Banco de dados relacional (PostgreSQL + TypeORM)

 

 

```bash
npm run generate:resource:relational -- --name=Category
```

 
## Adicionar propriedade no recurso

### Propriedade  para banco relacional (PostgreSQL + TypeORM)
 
```bash
npm run add:property:to-relational
```
